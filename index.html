Connect this device

One time per device. This lets the Hub and every one of your apps save flags straight to your flag-hub repo. The key stays on this device and only works on flag-hub.

  1. Open GitHub's new token page.
  2. Name it Flag Hub. Expiration: the longest it allows.
  3. Repository access: Only select repositories, then pick flag-hub.
  4. Permissions: Contents, set to Read and write. Leave everything else alone.
  5. Tap Generate, copy the key, and paste it here.
